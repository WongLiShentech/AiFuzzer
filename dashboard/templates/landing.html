What it detects

Four high-impact vulnerability classes, on real contracts.

Reentrancy

Funds drained by re-entering a contract before it updates its books.

Access Control

Privileged functions callable by accounts that were never authorised.

Ordering Attacks

Outcomes that depend on transaction order — front-running and TOD.

Oracle Manipulation

Pricing logic that trusts a manipulable on-chain price source.

How it works

1

Submit a contract

Drop a Solidity file or paste source. Your code never leaves your machine — everything runs locally in Docker.

2

Fuzz in a local EVM

Echidna generates thousands of random transaction sequences, trying to break the contract's security invariants.

3

Get an exploit report

A clear VULNERABLE / CLEAN verdict, the offending code, and the exact transaction sequence that triggers it.
